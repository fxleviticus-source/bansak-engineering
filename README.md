## Design
- Signature motif: the stamped "equipment nameplate" — used for the logo badge (BE monogram),
  section eyebrows, the company info block, and the footer, echoing the ID plates found on
  real engineering machinery.
- Palette: charcoal/graphite darks, warm paper light sections, bronze/copper accent
  (chosen to tie directly to the company's own bronze billet & non-ferrous metal work).
- Typography: Oswald (display), Public Sans (body), IBM Plex Mono (technical labels/eyebrows).
- No logo was supplied, so a text-based "BE" monogram badge was built instead — swap this out
  in the `.brand-mark` markup (all 4 pages) if a real logo file becomes available.
